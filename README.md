# Overlap

**What crosses and what stays when AI work meets team work.**

Overlap is a clickable prototype from my MFA Interaction Design thesis at SVA. It explores how one person moves their own AI-assisted work into the way their team works, without turning that into surveillance.

- **My chats** looks like a normal AI chat, with a branch map beside it. Every answer is a node. Answers are private by default, and you choose which ones can cross into the team space.
- **Team map** is a floating bubble map of what the team is exploring, grouped by topic and linked when ideas relate. You see what a chat is about and who to ask, never the chat itself.

## Try it

Open the live page (GitHub Pages), or download this folder and open `index.html` in a browser.

Demo path: search "onboarding", open a teammate's bubble, press **New chat**, share an answer, branch from an earlier one, then **Add to team map**. Use **Reset demo** to start over.

## Notes

- All data is made up for the demo. Nothing is saved or sent anywhere.
- Built with plain HTML and [Preact](https://preactjs.com/) + [htm](https://github.com/developit/htm), bundled in `preact-htm.js` so the page has no build step.
